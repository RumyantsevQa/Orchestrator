# Скриншоты для GitHub

Перед публикацией нужно снять 5 скриншотов. Все скриншоты должны быть сделаны
на demo-данных.

## 1. Структура проекта

Показать:

- `app/`
- `tests/`
- `demo/`
- `docs/`
- `.github/workflows/ci.yml`

Команда:

```bash
tree -L 2 -I '.git|.venv|__pycache__|.pytest_cache|.qaskills'
```

## 2. Проверка готовности

Показать вывод:

```bash
./qaskills doctor
```

Должно быть видно, что vault/index доступны или что система явно объясняет,
какой компонент не настроен.

## 3. Поиск по знаниям

Показать:

```bash
./qaskills find authorization
```

Должны быть видны найденные документы, пути и причины совпадения.

## 4. AI-контекст без LLM

Показать:

```bash
./qaskills ask "Что проверить в авторизации?"
```

Важно показать fallback: система полезна даже без внешней модели.

## 5. CI

Показать зелёный GitHub Actions workflow: lint + tests.
